# Fixtures

Only hand-authored synthetic CT XML is included. `synthetic.CT` is inventory test data, not a working injection script and must not be activated against any process. It uses invented module names and byte patterns. It exercises nesting, AA sections, a scoped AOB, allocation/symbol operations, embedded Lua and a root Lua script.

Do not add proprietary binaries, executables, memory dumps or third-party tables without appropriate rights. Prefer tiny synthetic cases that isolate one parser behavior.
